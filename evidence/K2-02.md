- Назначение инструкций Dockerfile:
  - `FROM`: базовый родительский образ (Python 3.13).
  - `WORKDIR`: задание рабочей директории внутри контейнера для последующих команд.
  - `COPY`: перенос файлов проекта (app.py, index.html) из контекста сборки внутрь образа.
  - `RUN`: выполнение команд на этапе сборки (создание /data и назначение прав).
  - `USER`: запуск процессов от непривилегированного пользователя (10001) ради безопасности.
  - `EXPOSE`: документирование порта (8000), на котором приложение слушает трафик.
  - `CMD`: команда по умолчанию, выполняемая при старте контейнера.

- Ответ на вопрос из задания: 
  Вопрос: Почему указания EXPOSE в Dockerfile недостаточно, чтобы открыть приложение через браузер? Для чего нужен параметр -p?
Инструкция `EXPOSE` это документация и сама по себе не пробрасывает порты вне. Чтобы порт контейнера стал доступен в браузере, необходим флаг `-p` (т.е. publish), который создает правило маршрутизации в сети между портом хоста и портом контейнера.
